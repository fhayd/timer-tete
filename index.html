🍼 Configuration requise


1. Créer la base de données (gratuit, ~5 min)

  1. Aller sur console.firebase.google.com et créer un projet.
  2. Menu Realtime Database → Créer une base de données → mode test.
  3. Dans Paramètres du projet, section « Vos applications », ajouter une application Web et copier l'objet firebaseConfig.
  4. Coller cet objet dans le fichier index.html, à la place du bloc FIREBASE_CONFIG en haut du script.

2. Règles de sécurité

  1. Dans Realtime Database → Règles, coller :
{
  "rules": {
    "familles": {
      "$famille": { ".read": true, ".write": true }
    }
  }
}
  1. Le nom de famille dans l'URL (#famille=...) sert de clé d'accès : choisissez-en une longue et aléatoire, et partagez uniquement l'URL complète entre vous.

3. Héberger la page

  1. Mettre index.html et sw.js sur un hébergement statique (GitHub Pages, Netlify, Firebase Hosting…).
  2. Ouvrir la même URL complète sur les deux téléphones, puis activer les notifications.
